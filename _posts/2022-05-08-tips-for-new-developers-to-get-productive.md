# About
This post is intended to get new developers up-to-speed quickly on the best software
engineering practices. These tips are tailored for remote developers.

The material used to live in one long post, but it really covers two distinct topics,
so it has been split into two focused reads:

 * [Technical tips for new developers](/2022/05/technical-tips-for-new-developers.html) - clean code, testing, and design fundamentals: initial readings, keeping things simple, writing tests first, avoiding nulls, SOLID, and the basics of domain driven design.
 * [Work habits and systems for new developers](/2022/05/work-habits-and-systems-for-new-developers.html) - working culture and process: asynchronous communication, asking good questions, task and code management, and Scrum.

Start with whichever is more relevant to you - together they should be enough to get you started on the right track.
